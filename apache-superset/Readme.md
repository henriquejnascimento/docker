Passo a Passo Obrigatório (Antes de ligar o Superset)
Abra o seu pgAdmin (que está em http://localhost:5050).

Conecte-se no seu servidor Postgres.

Clique com o botão direito em Databases > Create > Database...

No nome, digite exatamente: superset e salve.
(Pronto, agora seu Postgres está preparado para receber os dados do Superset sem misturar com o seu mydatabase de negócio).
